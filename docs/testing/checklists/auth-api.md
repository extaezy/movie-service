# Авторизация через API

Актуальные сценарии, основное место каждой проверки и ограничения находятся в [матрице покрытия](../coverage.md#авторизация). Команды запуска — в [инструкции](../README.md).

API-тесты с подменённым репозиторием проверяют валидацию, нормализацию входных данных и JWT. PostgreSQL-тесты проверяют сохранение пользователя и профиля, вход, права текущего пользователя, конфликты и откат транзакций.
