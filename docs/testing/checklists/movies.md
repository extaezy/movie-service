# Ручная проверка фильмов

Чек-лист проверяет пользовательский интерфейс с запущенными frontend/backend. API, импорт и ограничения БД проверяются автоматически по [матрице требований](../coverage.md).

| ID | Действие | Ожидаемый результат |
|---|---|---|
| MOV-UI-001 | Открыть каталог и дождаться ответа | Видны загрузка и карточки фильмов; постеры и названия отображаются корректно |
| MOV-UI-002 | Найти фильм и применить предусмотренные фильтры/сортировку | Параметры интерфейса соответствуют выдаче; переход страницы сохраняет выбранные условия |
| MOV-UI-003 | Получить пустую выдачу | Показано понятное пустое состояние, доступны изменение запроса и повторный поиск |
| MOV-UI-004 | Получить ошибку TMDB, затем повторить запрос | Видна ошибка; повторная попытка может вернуть обычную выдачу |
| MOV-UI-005 | Открыть фильм из поиска или витрины | Открыта нужная карточка с описанием, жанрами и длительностью; последующие действия используют внутренний ID |
| MOV-UI-006 | Открыть сохранённый фильм при недоступном TMDB | Локальная карточка отображается; отсутствующие необязательные значения не ломают интерфейс |
| MOV-UI-007 | Выполнить доступную мутацию на карточке с задержкой и ошибкой ответа | Кнопка заблокирована во время запроса, ошибка видна, повторное действие доступно после завершения |

Проверки операций оценок, списков и рецензий вместе с правами владельца остаются отдельной задачей QA. Этот чек-лист не объявляет их покрытыми.

Исправленный дефект поиска: [BR-MOV-001](../bug-reports/BR-MOV-001.md).
